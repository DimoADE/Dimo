# Agent 纳入关系独立于安装状态与 Registry 可用性

Dimo 用独立的纳入关系（Membership，“已添加”）表达 Agent 是否属于当前用户的 Agent 集合，将其与安装状态、启用状态、认证状态及上游 Registry 可用性解耦。

## Decision

### 1. 纳入、启用与安装正交

- 20 个预置 Built-in Agent 默认已添加；官方 ACP Registry Agent 在用户确认“添加并安装”时立即获得 membership、进入统一 Agent 导航带，并在其详情页继续安装、预检查、认证与修复；用户声明 Agent 在保存定义时原子获得 membership（见 [ADR-0036](0036-user-declared-acp-agents-use-locked-distributions.md)）。
- 安装中、失败、取消、中断、待认证或需修复均不撤销 membership，并保留配置与启用状态。失败显示为需要修复，中断显示为安装已中断，均等待用户显式重试而不在下次启动时自动重跑。取消或中断只清理未提交的暂存产物，不触碰用户环境中的既有安装（见 [ADR-0060](0060-agent-installs-use-user-environment.md)）。
- 上游 Registry 下架仅使条目从 Registry 视图消失，不会移除本地 Agent 导航带中已添加的 Agent。
- 启用状态独立于纳入、安装与认证。禁用的 Agent 继续显示且允许安装、修复、认证与配置，但不能创建新会话或提交新 Turn（已在途的 Turn 允许自然结束）；禁用不卸载包、不注销账户、不删除凭据。默认启用（随预置目录配置或新添加的 Registry Agent）仅代表允许在就绪后执行，不绕过安装、认证或预检查门槛。

### 2. 导航带、Registry 视图与状态表达

- **扁平用户排序**：Agent 导航带维护一套由用户控制的扁平顺序，内置 Agent 与其他 Agent 可自由交错；新添加条目追加到右侧固定添加入口之前。空间不足时导航带横向滚动、两侧渐隐提示，右侧固定添加入口常驻可见，键盘或辅助技术聚焦不可见项时自动滚入视野。
- **内联 Registry 视图**：导航带末位添加入口在设置页详情区域内联打开完整的官方 ACP Registry 主视图（非模态框），顶部导航带始终保留。视图包含独立排序的“已添加 / 可添加”两个 Tab（内置条目在“已添加”置顶，其余按名称排序）、搜索（覆盖名称、简介、作者、Registry ID）、刷新状态与快照时间；选择其他 Agent、返回或按 Escape 回到上次选中项，并在当前访问期间保留 Tab、搜索词与滚动位置。
- **紧凑列表与内联展开**：Registry 两个 Tab 均采用紧凑分组列表行，展示图标、名称、一行简介、版本、可用分发方式（内置仅加低调标签，状态由图标+文字+颜色共同表达）。点击行主体以内联 disclosure 展示作者、许可证、仓库链接、Registry ID 与完整分发信息；移除与卸载等破坏性操作仅位于 Agent 详情页。因视图限定为官方 Registry，每行不重复展示官方来源徽章。
- **平台兼容性**：Registry 展示所有当前官方条目，包含不支持当前 OS/架构的条目（明确标注缺失目标并禁用添加）；已添加 Agent 若因换机或上游变更不再支持当前平台，仍保留在导航带并标记为平台不支持而非安装损坏。
- **状态徽标与图标**：导航带图标右上角用单一徽标表达最高优先级健康/就绪态（就绪绿点、排队/安装中进度环、待认证/缺配置琥珀提醒、损坏/完整性异常红色修复、平台不支持灰色斜杠、未安装空心点）；禁用状态通过降饱和与暂停标记正交表达，不与健康徽标互斥。悬停、键盘焦点与 `aria-label` 同时提供名称、启用态与完整原因。Built-in Agent 使用 Profile 品牌图标；Registry Agent 使用经校验并本地缓存的 SVG（渲染时不发网络请求，上游下架后保留最后有效图标）；缺失或无效时回退通用 ACP 图标，不使用首字母头像。

## Consequences

- 用户的 Agent 导航与配置布局不受短暂网络波动、安装中断或上游目录变动破坏。
- 状态表达在导航带、Registry 列表与详情页保持一致且无信息遮蔽。
