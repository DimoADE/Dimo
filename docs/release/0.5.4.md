# Dimo 0.5.4

## 中文

Dimo 0.5.4 围绕高频工作台体验、桌面冷启动速度、数据库与运行环境稳定性以及跨平台发布可靠性带来全面升级：内置浏览器上线可折叠悬浮「元素晾晒区」并在无限画布中实现原生内联 `<webview>` 渲染；协作空间 Bot 详情页新增「任务（Tasks）」自动化管理页签；会话输入框支持长文本粘贴芯片；完成桌面端三层冷启动提速、SQLite 读写分离与 FTS5 索引/自愈优化、子进程凭据隔离与进程树回收加固，并彻底修复共享插件 Worker 死锁与连接池耗尽问题。

### 一、新增

1. **内置浏览器元素晾晒区与无限画布原生渲染**
   - 内置浏览器新增毛玻璃悬浮「元素晾晒区」，点击选择网页元素后以单列纵向卡片暂存，支持拖拽调节高度、双击标题栏或点击按钮折叠为可自由拖拽的悬浮球，以及将选中元素直接拖入会话输入框。
   - 无限画布中的浏览器节点全面切换为原生内联 Electron `<webview>` 渲染，移除旧版离屏与静态帧兼容路径，与浏览器标签页保持一致的实时浏览与交互体验。

2. **协作 Bot 自动化任务页签（Tasks）**
   - 协作空间 Bot 详情页新增「任务」页签，支持一站式查看、创建、编辑、测试触发与启停绑定到该 Bot 的事件触发和定时任务。
   - 支持直接审批观察模式（Observe）命中候选、切换邮箱投递策略与会话作用域（主会话 / 按主题分会话），并在联系人右键菜单提供快捷创建触发器与定时任务入口。

3. **会话输入框长文本粘贴芯片**
   - 在会话输入框粘贴较长文本时自动折叠为紧凑交互芯片（展示行数与字符数），支持悬停预览、展开回正文、一键复制与移除；同步增强 `@` 智能体提及与结构化令牌序列化体验。

4. **桌面开发者工具与窗口刷新控制**
   - Electron 桌面端新增窗口刷新（`F5`）、强制刷新（`Ctrl+Shift+R` / `Cmd+Shift+R`）与检查元素命令，并在开发者模式及开发会话中接入统一右键开发者菜单与崩溃回退原生菜单。

### 二、优化

1. **桌面端三层冷启动提速与高并发运行性能**
   - 实施三层冷启动架构优化：数据库数据目录路径迁移幂等化、两阶段 `dimo-server --desktop` 启动与插件 Worker 按需懒加载、Electron 窗口渲染与 Sidecar 拉起并行化，大幅缩短冷启动等待时间。
   - 将同步文件树监听初始化、大仓库 Diff 计算与插件包内容哈希下放至 Tokio 阻塞线程池，消除异步执行器饥饿；PTY 终端输出按 16ms / 32 KiB 窗口合并推送，显著降低高频输出时的事件总线压力。
   - Electron 预热设置窗口接入闲置自动回收机制，避免后台隐藏窗口常驻占用内存。

2. **无限画布、自由标签分栏与会话时间线渲染性能**
   - 将无限画布点阵背景、节点连线与右键拖拽平移解耦出 React 提交流程，结合 GPU 合成优化显著提升画布平移与缩放帧率。
   - 消除自由标签（Free Tabs）模式下拖拽分栏分隔条（Dockview Sash）时的卡顿与会话内容白屏闪动，批量合并 DOM 读写、去重正交轴 `ResizeObserver` 回调并同步对齐虚拟列表滚动位置。
   - 会话输入框切换为按当前会话隔离的细粒度时间线订阅并对实时反馈刷新增加防抖；消息轮次视图惰性渲染尾部文本；浏览器宿主组件与 WebView 引入 `useShallow` 与 `memo` 减少无关重渲染。
   - 升级 Git Worktree 与分支选择器，支持目录与分支层级导航及即时搜索过滤；优化自由标签指针拖拽体验与权限请求卡片视觉呈现。

3. **数据库并发读写分离、检索加速与崩溃自愈**
   - 将服务端鉴权查询与会话事件录制热路径的活跃绑定查询切换至 `ReadPool`，辅以带上限的 Epoch 缓存与主键索引查询，降低对单写连接池 `WritePool(1)` 的争用；执行日志改为 50ms / 32 KiB 批量写库；定期 WAL 维护补充 `PRAGMA optimize`。
   - 为全文检索引入伴生索引表 `conversation_fts_rowids`，将 FTS5 删除降为 O(1) 主键定位，并在回填时自动去重历史重复行。
   - 备份快照改为 fail-closed 策略并将 `VACUUM INTO` 超时放宽至 60s，杜绝热库不完整打包；Pulse 自动化运行时新增启动期崩溃自愈，自动恢复异常退出遗留的 `in_flight` Outbox 与 `claimed` / 同批 `coalesced` Bot 轮次。

4. **用户环境安全隔离、代理兼容与跨平台体验**
   - `dimo-server` 启动早期即捕获并从进程环境中清除 `DIMO_DESKTOP_TOKEN` / `DIMO_SERVER_TOKEN`，同时在 Agent、终端、PTY 与插件 Worker 全部子进程拉起处实施纵深脱敏，防止宿主凭据泄露；Unix 凭据文件创建即设 `0o600` 权限。
   - 为本地预览代理显式启用 `.no_proxy()` 并在同步代理环境变量时自动合并回环地址豁免，防止系统代理拦截本地回环请求。
   - 优化 Shell `PATH` 合并优先级、按语义化版本降序发现运行时（稳定版优先于预发布版）及 Unix 登录 Shell 哨兵提取；Windows 端通过 `winreg` 原生读取 `MachineGuid` 替代拉起 PowerShell，日志读取改为尾部 2 MiB 截断防 OOM，Worktree 清理增加只读清除与退避重试。
   - 加固智能体启动探测、Codex 原生协议与引擎处理、Pi 信任策略、Antigravity 认证与技能加载流程；插件快照改为原子暂存并自动迁移历史 `vibe_x` 格式；升级 Windows NSIS 自定义主题安装程序。

### 三、修复

1. **共享插件 Worker 死锁与连接池耗尽（设置页骨架屏 / 新建会话代理列表加载失败）**
   - 修复共享 Node 插件 Worker 在 `host.call` 回调内发生可重入调用时的互斥锁死锁，避免宿主命令队列阻塞。
   - 修复内置浏览器偏好存储 `browserPrefsStore` 在多标签下重复并发拉取耗尽连接池的问题，并为 `WebTransport` 引入并发隔离舱（Bulkhead），根治高并发请求导致的设置页持续骨架屏与新建会话代理列表无法加载问题。

2. **SQLite FTS5 索引损坏自愈与数据目录迁移修复**
   - 数据库启动与迁移前自动探测损坏的 FTS5 虚拟表（如历史重置残留引发的 `SQLITE_CORRUPT_VTAB`）并重建空索引，同时完好保留健康索引数据。
   - 修复数据目录接管统计误查旧表及并发锁等待缺失问题，并修复服务端访问令牌在 `TEXT` 与 `BLOB` 主键并存时的活性校验兼容性。

3. **Windows 中文路径、进程树清理与交互回归修复**
   - 修复 Windows 非 ASCII（中文用户名）路径下 `.cmd` Shim 乱码及 `\\?\` 扩展路径前缀导致命令行执行失败的问题；加固插件 Worker、预览宿主与 PTY 的进程树清理机制，防止孙进程孤儿化与 Unix 回收后 PGID 复用误杀。
   - 修复无限画布中浏览器节点首次加载显示白屏、拖拽画布时晾晒区脱离节点或受双重边界裁剪、元素选择按钮激活态图标未变蓝、热更新后晾晒区未同步刷新以及双击标题栏无法折叠的问题。
   - 修复将浏览器元素或其他结构化令牌插入空会话输入框时，默认占位提示文字未消失的问题。

4. **智能体驱动与跨平台发布链路修复**
   - 修复 Claude 原生驱动从目录联接（Junction）路径启动时静默退出的问题（#129）。
   - 修复 Windows EVSign 签名目标范围、Windows NSIS 进程检测钩子与侧车构建 Shell、Linux `.deb` 包主页字段以及 macOS 空签名凭据跳过逻辑。

## English

Dimo 0.5.4 delivers major upgrades across workbench UX, desktop cold-start speed, SQLite concurrency and resilience, host environment security, and cross-platform reliability. Highlights include a collapsible floating Element Staging Rack and native inline Electron `<webview>` rendering for Infinite Canvas browser nodes, a Bot Tasks automation tab in Collaboration Spaces, compact pasted-text chips in the session composer, a three-layer cold-start speedup, SQLite read/write separation and FTS5 optimizations, host credential scrubbing and process-tree hardening, and root-cause fixes for plugin worker deadlocks and browser connection-pool exhaustion.

### Features

1. **Built-in Browser Element Staging Rack and Native Inline Canvas Webview**
   - Added a frosted-glass floating Element Staging Rack inside the built-in browser to collect picked page elements as vertical single-row cards with adjustable height, double-click header collapse into a draggable floating ball, and direct drag-and-drop into the session composer.
   - Switched Infinite Canvas browser nodes to native inline Electron `<webview>` rendering, removing legacy offscreen and static-frame workarounds for consistent real-time interaction matching browser tabs.

2. **Collaboration Bot Automation Tasks Tab**
   - Added a dedicated **Tasks** tab inside Bot Details to view, create, edit, test-trigger, toggle, and delete event triggers and scheduled Pulse rules bound to a bot.
   - Added one-click approval for Observe-mode candidate matches, mailbox policy and session scope controls (Primary thread / Per topic), and quick-create actions in the contact row context menu.

3. **Session Composer Long-Paste Text Chips**
   - Automatically folds large pasted text blocks into compact interactive chips showing line and character counts, with hover preview, expand-to-text, copy, and remove actions, alongside improved `@` agent mentions and structured token handling.

4. **Desktop Developer Controls and Reload Shortcuts**
   - Added `reload_window`, `force_reload_window`, and `inspect_element` Electron commands, keyboard reload shortcuts (`F5`, `Ctrl+Shift+R` / `Cmd+Shift+R`), integrated context-menu developer actions, and a fallback native developer menu for error screens.

### Improvements

1. **Three-Layer Desktop Cold-Start Optimization and Runtime Throughput**
   - Implemented a three-layer startup speedup: idempotent SQLite data-directory path migration, two-phase `dimo-server --desktop` initialization with on-demand lazy plugin worker activation, and parallel Electron window + sidecar startup, substantially reducing launch latency.
   - Offloaded synchronous file-tree watcher setup, workspace diff population, and plugin package content hashing to Tokio blocking threads to prevent async executor starvation, and coalesced PTY output chunks over a 16 ms / 32 KiB window on `HostEventBus`.
   - Scheduled idle destruction for prewarmed hidden Electron Settings windows so unused background windows do not retain memory indefinitely.

2. **Infinite Canvas, Dockview Sash, and Session Timeline Performance**
   - Decoupled Infinite Canvas dot-grid background, link edges, and right-drag panning from React commits with GPU-friendly layer hints for smooth pan and zoom.
   - Eliminated Free Tabs Dockview sash drag stutter and session white flashes by suspending heavy effects mid-drag, batching DOM height measurements before writes, deduplicating orthogonal `ResizeObserver` callbacks, and synchronously aligning virtualized list scroll offsets before paint.
   - Scoped `TaskFollowUpSection` timeline subscriptions per active session with debounced live-feedback refreshes, made trailing prose rendering lazy in `MessageTurnView`, and memoized `HostedElectronBrowserWebview` with `useShallow` selectors.
   - Upgraded the Git Worktree and branch selector with directory/branch navigation and instant filtering; refined Free Tabs pointer drag-and-drop and permission request cards.

3. **SQLite Concurrency, Search Indexing, Backup Integrity, and Pulse Crash Recovery**
   - Routed server authentication and hot-path conversation active-binding lookups to `ReadPool` with bounded epoch-invalidated caching and primary-key indexed queries, batched execution log writes over a 50 ms / 32 KiB window, and added `PRAGMA optimize` to periodic WAL maintenance.
   - Added a `conversation_fts_rowids` companion index for O(1) FTS5 deletes and drop-safe `BEGIN IMMEDIATE` backfill with automatic deduplication of legacy duplicate FTS rows.
   - Made desktop SQLite backup snapshots fail-closed with a 60 s `VACUUM INTO` budget, and added startup crash recovery in Pulse to requeue stuck `in_flight` outbox rows and `claimed` (plus sibling `coalesced`) bot mailbox turns.

4. **Host Environment Security, Proxy Bypass, and Cross-Platform Hardening**
   - Captured and scrubbed `DIMO_DESKTOP_TOKEN` and `DIMO_SERVER_TOKEN` from `dimo-server`'s environment before Tokio runtime initialization, with defense-in-depth scrubbing across agent, terminal, PTY, preview, and plugin worker spawns; created Unix credential files with `0o600` permissions atomically.
   - Enabled `.no_proxy()` on loopback preview proxy clients and automatically merged loopback entries into `NO_PROXY` / `no_proxy` when syncing proxy environment variables.
   - Fixed desktop `PATH` fallback ordering, sorted discovered Node/runtime version directories by semver (stable ahead of prerelease), hardened Unix login-shell `PATH` extraction with sentinels and lossy UTF-8 decoding, switched Windows `MachineGuid` lookup to native `winreg` (no PowerShell spawn), bounded `get_recent_logs` to a 2 MiB tail read, and added Windows-safe worktree deletion retries.
   - Hardened agent launch probing, Codex protocol/engine handling, Pi trust, Antigravity authentication, and skill loading; switched plugin snapshot staging to atomic swaps with `vibe_x`-to-`dimo` migration; shipped a custom-themed Windows NSIS installer.

### Fixes

1. **Plugin Worker Re-Entrant Deadlock and Connection-Pool Exhaustion**
   - Resolved a re-entrant mutex deadlock when shared Node plugin workers invoked `host.call` back into the host during active requests.
   - Fixed `browserPrefsStore` connection-pool exhaustion across multiple tabs and added a concurrency bulkhead in `WebTransport`, eliminating persistent Settings skeleton screens and stalled agent-list loading in the New Session dialog.

2. **Self-Healing SQLite FTS5 Recovery and Migration/Auth Fixes**
   - Automatically detects and recreates corrupt FTS5 virtual tables (such as `conversation_fts` affected by `SQLITE_CORRUPT_VTAB` after legacy resets) before migrations or queries run while preserving intact indexes.
   - Fixed `inspect_sqlite_content_summary` to inspect canonical `sessions` rows with `busy_timeout`, and ensured `SqliteServerAuth::is_active` matches both `TEXT` and `BLOB` primary keys on `server_access_tokens`.

3. **Windows CJK Paths, Process-Tree Cleanup, and UI Regressions**
   - Normalized Windows verbatim `\\?\` path prefixes and emitted `chcp 65001 >nul` in Windows `.cmd` shims when paths contain non-ASCII characters; unified `ProcessTreeJob` cleanup across plugin workers, preview hosts, PTYs, and terminals while disarming jobs on reap to prevent orphan grandchildren and Unix PGID-reuse hazards.
   - Fixed Infinite Canvas browser nodes rendering blank white on initial URL load, the staging rack detaching during canvas drags or hitting dual bounds, the element-picker active icon state, stale staging rack state across dev HMR reloads, and header double-click collapse.
   - Fixed the session composer placeholder failing to hide when dragging a browser element or inserting a structured token into an empty composer.

4. **Agent Driver and Cross-Platform Release Pipeline Fixes**
   - Fixed the Claude native driver silently exiting when launched through a directory junction (#129).
   - Scoped Windows EVSign signing strictly to NSIS installers, fixed the Windows NSIS process-check hook and sidecar build shell, fixed Linux `.deb` package homepage metadata, and fixed empty macOS signing credential handling.
