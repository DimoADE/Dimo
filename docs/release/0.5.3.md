# Dimo 0.5.3

## 中文

Dimo 0.5.3 完成桌面端向 **Electron 轻壳 + `dimo-server --desktop` 侧车进程** 架构的全面迁移与安全加固，新增 **Muse Code** 原生智能体引擎支持，引入标签页与无限画布一键交接、Git 提交图谱与 Worktree 分支筛选、会话输入区工作区上下文切换、Plugin Dev 本地热重载控制面以及本地语音模型能力，并修复多项跨平台与并发稳定性问题。

### 一、新增

1. **全新 Electron 桌面壳与 `dimo-server --desktop` 侧车架构**
   - 桌面应用全面迁移至 Electron 轻量化桌面壳，统一复用 Rust 宿主侧车进程 `dimo-server --desktop`，与独立 Headless/Web 部署共享同一套 `HostCommandRegistry` 命令面与 `HostEventBus` 事件总线。
   - 内置宿主浏览器升级为基于 Electron `<webview>` 的宿主实现，支持多标签视口自适应布局、CDP 调试桥接与原生页面交互。
   - 发布包同时提供 Electron 自动更新源与 Tauri v2 桥接更新清单（`latest.json`），支持旧版 `v0.5.2` 桌面客户端平滑在线升级至新架构。

2. **Muse Code 原生智能体引擎与插件管理**
   - 新增 Muse Code 专用原生智能体引擎适配器、本地会话历史发现与导入以及原生模型提供方配置。
   - 在设置页新增 Muse 插件管理器，支持插件安装、审批、启停与移除。

3. **标签页转无限画布与工作台自动排布**
   - 支持将当前分栏标签页一键交接至无限画布作为空间节点（`Tabs -> Canvas`），并提供 Dockview 面板自动排布能力，方便多会话并行浏览。

4. **Git 面板提交图谱与 Worktree 分支管理**
   - Git 面板新增分支过滤、Worktree 分支选择器、提交图谱拓扑布局渲染以及只读分支 Diff 浏览模式。
   - 会话输入栏底部新增工作区上下文条与快速切换器，可在不离开对话的情况下查看或切换当前工作区与分支上下文。

5. **Plugin Dev 本地开发控制面与语音输入本地模型**
   - 新增独立回环 Plugin Dev Control Protocol 1.0 控制面，支持本地插件 linked 安装、`doctor` 诊断、候选版本热重载与清理卸载。
   - 官方 `voice-input` 语音输入插件新增本地语音模型管理、原生语音识别、麦克风选择与快捷浮层 HUD。

6. **多智能体协作引导与系统事件消息**
   - 协作空间新增 Supervisor 成员配置引导卡，并在建群与成员变更时自动写入结构化系统消息，提升团队协作过程的可追溯性。

### 二、优化

1. **桌面主进程生命周期与安全边界全面加固**
   - 强化 Electron 文件系统路径白名单授权、自定义协议 `dimo-app://` 与深链 `dimo://` 校验、严格应用 CSP（兼容 WASM 与局域网预览）、制品访问鉴权与拖放拦截。
   - 加固 Sidecar 标准输出排空、崩溃自动重启与进程树回收、WebSocket 滞后重同步以及桌面数据目录备份/恢复与升级保护。
   - 完善 Windows EVSign 代码签名链路、macOS 麦克风/相机权限与公证校验，以及 Linux 桌面窗口控制与通知体验。

2. **架构文档体系重构**
   - 新增文档总索引 `docs/INDEX.md`，沉淀 Electron 轻壳（`ADR-0090`）、SQLite 单权威对话投影（`ADR-0091`）、Pulse 事件驱动自动化（`ADR-0092`）及跨智能体续接规范（`docs/specs/cross-agent-continuation.md`），并清理过期计划文档。

### 三、修复

1. **后端并发、栈安全与跨平台修复**
   - 拆分并装箱宿主命令分发器（`ServerHostDomains::dispatch_command`）的异步分支，消除 Windows 2 MB 默认线程栈下的栈溢出风险。
   - 修复 Plugin Dev 服务在加载无 Worker 入口的纯 Skill 插件时误触发 Node.js 下载超时的问题，并避免覆盖已记录的受管 Worker 运行时路径。
   - 修复 Windows 多线程目录可写探测临时文件竞争、云中继单元测试全局状态串扰，以及 Windows 路径与 Linux/macOS 条件编译兼容性问题。
   - 升级 `js-yaml` 至 `>=4.3.2` 修复生产依赖高危安全告警，并同步修正前端设计 Token、Markdown/Mermaid 渲染与面板交互回归。

## English

Dimo 0.5.3 completes the migration to a lightweight **Electron desktop shell backed by the `dimo-server --desktop` sidecar**, introduces native **Muse Code** agent engine support, adds Tabs-to-Canvas handoff, Git commit graph and worktree selectors, a composer workspace switcher, the Plugin Dev live-reload control plane, and local voice-input models, alongside key cross-platform and concurrency stability fixes.

### Features

1. **Electron Desktop Shell and `dimo-server --desktop` Sidecar**
   - Migrated the desktop application to a thin Electron shell supervising the Rust `dimo-server --desktop` sidecar, unifying Desktop and headless `dimo-server` deployments on the exact same `HostCommandRegistry` and `HostEventBus` seams.
   - Rebuilt the integrated host browser on Electron `<webview>` with multi-tab viewport layout management and CDP bridge support.
   - Publishes both native Electron updater feeds and a Tauri v2 bridge manifest (`latest.json`) so existing `v0.5.2` desktop installations can auto-upgrade seamlessly.

2. **Native Muse Code Agent Engine and Plugin Manager**
   - Added a dedicated native engine adapter for Muse Code, local session history discovery/import, and native model provider support.
   - Added `MusePluginManager` in Settings to install, approve, toggle, and remove Muse plugins.

3. **Tabs-to-Canvas Handoff and Dockview Auto-Arrange**
   - Added one-click handoff from tabbed Dockview panels into Spatial Infinite Canvas nodes along with automatic Dockview layout arrangement for multi-session workflows.

4. **Git Commit Graph, Branch Filtering, and Composer Workspace Context**
   - Enhanced the Git panel with branch filtering, a worktree branch selector, commit graph topology layout, and read-only branch diff browsing.
   - Added a workspace context footer and switcher inside the session composer for quick workspace inspection and switching without leaving the active thread.

5. **Plugin Dev Control Plane 1.0 and Local Voice Models**
   - Added a dedicated loopback Plugin Dev server (`Plugin Dev Control Protocol 1.0`) supporting linked installs, `doctor` diagnostics, candidate hot reload, and clean uninstalls.
   - Expanded the official `voice-input` plugin with local speech model management, native speech recognition, microphone selection, and a quick-access HUD overlay.

6. **Collaboration Supervisor Onboarding and System Events**
   - Added a Supervisor provisioning card in collaboration spaces and structured system messages for space creation and roster updates.

### Improvements

1. **Electron Lifecycle, Packaging, and Security Hardening**
   - Enforced main-process filesystem path authorization, custom `dimo-app://` protocol and `dimo://` deep-link validation, strict application CSP (with WASM and LAN preview support), artifact authentication, and drag-and-drop guards.
   - Hardened sidecar stdout draining, bounded auto-restart with process-tree cleanup, WebSocket lag resynchronization, and desktop backup/restore and host upgrade guards.
   - Refined Windows EVSign code-signing verification, macOS entitlements and notarization checks, and Linux window controls and notifications.

2. **Documentation Architecture Cleanup**
   - Introduced `docs/INDEX.md` as the documentation router, added canonical architecture records for Electron (`ADR-0090`), SQLite single-authority conversation projection (`ADR-0091`), Pulse automation (`ADR-0092`), and cross-agent continuation (`docs/specs/cross-agent-continuation.md`), and removed obsolete planning drafts.

### Fixes

1. **Backend Concurrency, Stack Safety, and Cross-Platform Stability**
   - Split and boxed command futures in `ServerHostDomains::dispatch_command` to eliminate stack overflow risks under Windows' 2 MB default thread stack.
   - Prevented the Plugin Dev server from downloading managed Node.js for workerless skill-only plugins and guarded `worker_restore` against being overwritten by placeholder paths.
   - Fixed a Windows multi-threaded writable-directory probe race (`directory_is_writable`), isolated host-tunnel unit tests from global state, and resolved Windows path and Linux/macOS conditional-compilation issues.
   - Upgraded `js-yaml` to `>=4.3.2` to resolve high-severity production advisories, and fixed frontend design-token, Markdown/Mermaid, and panel interaction regressions.
