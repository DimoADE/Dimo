# Dimo 0.5.5

## 中文

Dimo 0.5.5 在多智能体编排与跨主机委派、远程主机互联与端到端加密通道、应用重启后会话自动续跑、原生智能体瞬时控制体验以及统一 Markdown 渲染引擎上带来重磅升级：全新上线基于 SQLite 单一权威状态的多智能体编排引擎与统一 Streamable HTTP `/mcp` 网关（提供 18 个编排工具），支持本地多项目及跨配对主机异步委派；推出远程主机连通守护进程、一次性授权凭证、自定义公网入口与 Web 端到端加密连接；新增重启中断会话自动续跑、原生引擎零延迟控件基线与会话懒绑定，并集中解决跨窗口连接池饥饿、隐藏标签滚动复位、镜像下载校验回退与 Windows 安装路径校验等关键问题。

### 一、新增

1. **多智能体编排引擎、跨主机委派与统一 Streamable HTTP `/mcp` 网关**
   - `dimo-server` 新增回环 Streamable HTTP JSON-RPC 2.0 网关（`POST /mcp`），结合每会话 Bearer Token 解析调用者身份与权限，同时通过 `dimo-mcp` 兼容仅支持 stdio 的 ACP 引擎。
   - 提供完整的 18 个编排工具契约：能力与环境发现（`orchestrator_capabilities`、`environment_links`）、任务委派控制（`delegate_task`、`task_status`、`task_cancel`）、顶层会话编排（`thread_launch`、`create_threads`、`thread_list`、`thread_read`、`thread_send`、`thread_wait`、`thread_interrupt`、`thread_transfer`）、项目管理（`project_list`、`project_read`、`project_create`、`project_clone`）以及阻塞交互路由（`pending_request`）。
   - 所有委派记录、幂等回执与唤醒游标均落盘至 SQLite（`conversation_delegations`、`mcp_idempotency_receipts`）；支持两阶段延迟启动与真实 Git Worktree 隔离、单调权限上限（`OrchestrationModeLimit`）透传、子会话完成合并唤醒（`always` / `settled_only`）、子会话权限/提问路由、启动期状态对账以及首轮自动注入编排指引。
   - 支持指定 `environment_id` 将编排与委派转发至已配对的远程主机，并在发起端维护本地影子记录与后台状态轮询，返回 `dimo://conversation/<id>?env=<environment_id>` 深度链接。

2. **远程主机互联守护、端到端加密（E2EE）与隧道管理**
   - 服务端新增账号主机连通守护进程、一次性防重放主机授权校验（`consumed_host_grants`）、自定义公网源管理、无头/中继隧道管理以及稳定本机身份与机器指纹暴露。
   - 前端上线多主机选择器（`HostSelector`）、Happy Eyeballs 多端点探测、Web 端到端加密传输（`webE2ee`），以及全面升级的远程客户端、Web 服务与隧道设置面板。
   - 模型路由（Model Router）深链导入支持按目标 `hostId` 路由，并同步过滤本机局域网源避免回环重复同步。

3. **重启中断会话自动续跑**
   - 服务重启后启动恢复流程可自动将因重启中断的会话幂等重排至队首继续执行（受并发上限 3 与 5 分钟内 3 次防崩溃循环熔断保护），自动跳过存在待审批权限/提问、已归档/阻塞或由工作流/自动化托管的会话。
   - 在「通用设置」新增「重启后自动继续中断的对话」开关（默认开启），并支持原样重放未送达输入或通过原生恢复/便携式 SQLite 上下文无缝接续。

4. **统一 Markdown 渲染引擎**
   - 以基于 `unified` / `remark` / `rehype` 的全新渲染管线替换旧版原始 HTML Markdown 渲染器，完整支持 GFM Alert 提示块、折叠详情（`<details>`）、增强表格、Frontmatter 自动剥离、可交互任务复选框以及更清晰的排版层级。

### 二、优化

1. **原生智能体瞬时控件与会话懒绑定**
   - 为原生引擎提供零延迟内置能力基线，打开或切换会话时无需立即拉起子进程即可展示模式、模型与配置控件；将 Claude Code 与 Codex 初始化去阻塞（`skipModelProbe`、`models/list` RPC 与本地缓存发现），通过 `agent-capability-catalog-updated` 事件总线实时刷新前端缓存，并将实时会话绑定延迟至首轮发送时触发。
   - 自动记忆用户上次新建会话选用的智能体，作为下次创建会话的默认选项。

2. **Electron 跨窗口主进程 IPC 代理与数据库读写隔离**
   - 将桌面端本地 `HOST_COMMANDS` 与能力查询切换至 Electron 主进程白名单 IPC 零解析透传代理，彻底绕开 Chromium 主窗口与设置窗口共享的 6 连接 HTTP/1.1 连接池上限，并支持预加载能力缓存与 `AbortSignal` / 窗口销毁级联取消。
   - 限制客户端并发会话绑定数量（`MAX_CONCURRENT_SESSION_BINDS=2`）并优先保障可见面板；将后台负载压缩与已结算事件折叠扫描迁移至 SQLite `ReadPool` 并配合乐观并发校验，消除对 `WritePool(1)` 的读扫描争用。

3. **对话时间线、Fork 上下文交接与协作工作台体验**
   - 强化跨智能体及同智能体 Fork 会话交接：在源会话与子会话时间线双向写入成对交接分隔卡（展示来源模型、交接 Token 估算与快捷跳转链接），并升级输入框工作区与分支切换器。
   - 升级工具调用活动展示（`TurnActivity` / `TurnToolChips`），流式阶段合并为统一实时工具批次且展开态平滑衔接；优化浮动输入框高度测量（兼容画布缩放与延迟挂载），并在后台窗口未聚焦时暂缓将待审会话自动标记为完成。
   - 精简协作 Bot 自动化任务列表与规则提议卡片交互；更新提示徽章中的发布说明改为按需懒加载；放宽桌面端命令与 E2EE 请求体上限（最高 64 MiB）并将图片过大/格式非法等客户端错误规范映射为 4xx 响应。
   - 清理仓库中已退役模块（`crates/review`、`crates/dimo-workflow-mcp` 及遗留前端/打包冗余文件），进一步精简构建与包体。

### 三、修复

1. **隐藏会话切换后时间线滚动位置重置**
   - 修复从处于 `display:none` 的长会话标签切出再切回时，Chromium 将 `scrollTop` 重置为 `0` 并触发合成滚动事件导致脱离贴底状态的问题；隐藏时捕获滚动快照并在恢复可见或尺寸由 0 变为非 0 时同步还原。

2. **镜像下载错误页与 SHA-256 校验失败回退**
   - 修复 Windows 端通过镜像下载 MuseCode 及托管运行时（Node / uv / bun / Kiro）遇到 HTTP 200 HTML 错误页或校验和不匹配时直接中断安装的问题；改为在下载循环内逐候选源校验内容类型与 SHA-256 并自动回退官方源。

3. **OpenClaw Gateway 配置解析与本地双栈探测**
   - 修复 OpenClaw 预检因严格 JSON 解析拒绝官方 JSON5（注释/尾逗号）`openclaw.json`、忽略 `OPENCLAW_*` 环境变量及仅探测 IPv4 回环导致误报未监听的问题；现同时并发探测 `127.0.0.1` 与 `[::1]` 并给出更明确的本地/远程诊断指引。

4. **Windows NSIS 安装程序全新安装路径校验与其他稳定性修复**
   - 修复 Windows NSIS 安装程序使用内置 `GetFullPathName` 在目标安装目录尚未创建时清空路径导致全新安装被误判路径无效的问题，改用 Win32 `GetFullPathNameW` 与 `GetDriveTypeW` 完成规范化与驱动器校验。
   - 集中修复一批高优先级并发、工作流审阅恢复、Claude 原生驱动、本地文件路径/图片解析与桌面文件打开问题。

## English

Dimo 0.5.5 delivers major milestones across multi-agent orchestration and cross-host delegation, remote host connectivity with end-to-end encryption, automatic restart recovery for interrupted conversations, instant native session controls, and a unified Markdown rendering engine. Highlights include a SQLite-authoritative orchestration engine with a unified Streamable HTTP `/mcp` gateway (18 orchestration tools), remote host connectivity daemon and E2EE tunnels, auto-continuation after restart, zero-latency session controls with lazy binding, and critical fixes for cross-window HTTP/1.1 pool starvation, hidden timeline scroll resets, mirror download fallbacks, OpenClaw Gateway probing, and Windows NSIS fresh-install path validation.

### Features

1. **Multi-Agent Orchestration Engine, Cross-Host Delegation, and Unified Streamable HTTP `/mcp` Gateway**
   - Added a loopback Streamable HTTP JSON-RPC 2.0 endpoint (`POST /mcp`) on `dimo-server` with per-session Bearer token authentication and caller identity resolution, while preserving stdio ACP compatibility through `dimo-mcp`.
   - Exposed the complete 18-tool orchestration contract: discovery (`orchestrator_capabilities`, `environment_links`), delegation (`delegate_task`, `task_status`, `task_cancel`), top-level threads (`thread_launch`, `create_threads`, `thread_list`, `thread_read`, `thread_send`, `thread_wait`, `thread_interrupt`, `thread_transfer`), project management (`project_list`, `project_read`, `project_create`, `project_clone`), and blocked interaction routing (`pending_request`).
   - Persisted all delegation runs, idempotency receipts, and wakeup cursors in SQLite (`conversation_delegations`, `mcp_idempotency_receipts`) with two-phase deferred worktree launch, monotonic `OrchestrationModeLimit` ceilings, coalesced push completion wakeups (`always` / `settled_only`), child permission/question escalation, startup reconciliation, and first-turn orchestration instruction injection.
   - Added paired cross-host delegation forwarding via `environment_id` with local shadow-row tracking, background status polling, and `dimo://conversation/<id>?env=<environment_id>` deep links.

2. **Remote Host Connectivity Daemon, E2EE Transport, and Tunnel Management**
   - Added an account host connectivity daemon, single-use replay-protected host grant verification (`consumed_host_grants`), custom public origins, headless/relay tunnel management, and stable host identity / machine fingerprint exposure.
   - Added an upgraded multi-host selector (`HostSelector`), Happy Eyeballs multi-endpoint probing, Web E2EE transport (`webE2ee`), and redesigned Remote Client, Web Service, and Host Tunnel settings panels.
   - Supported target `hostId` routing in Model Router deep-link imports and filtered self LAN origins during host configuration sync.

3. **Auto-Continue Interrupted Conversations After Restart**
   - Startup turn recovery now idempotently enqueues front-of-queue continuations for turns interrupted by an app restart, guarded by pending permissions/questions, blocked/done/archived/deleted checks, workflow/automation ownership, a 3-in-5-minute crash-loop circuit breaker, and bounded concurrency (3).
   - Added a **Continue conversations after restart** (`continue_conversations_after_restart`) switch in General Settings (enabled by default), supporting exact replay of unaccepted inputs alongside native resume and portable SQLite handoffs.

4. **Unified Markdown Engine**
   - Replaced the legacy raw HTML markdown pipeline with a unified `remark`/`rehype` engine supporting GFM alerts, collapsible `<details>` blocks, enhanced tables, frontmatter stripping, interactive task checkboxes, and refined prose typography.

### Improvements

1. **Instant Native Session Controls and Lazy Session Binding**
   - Synthesized zero-latency bundled baseline controls for native engines so opening or switching sessions never blocks on spawning child processes; de-blocked Claude Code and Codex initialization (`skipModelProbe`, `models/list` RPC, cached discovery), added `agent-capability-catalog-updated` EventBus push with TanStack Query hydration, and deferred live session binding until turn start.
   - Persisted the last-selected session agent so new sessions default to the user's most recently chosen agent.

2. **Electron Main IPC Proxy and SQLite ReadPool Isolation**
   - Routed local desktop `HOST_COMMANDS` and capabilities through Electron Main's whitelisted zero-parse IPC proxy with preloaded capability caching and `AbortSignal`/window-destroy cancellation, eliminating Chromium's shared 6-connection HTTP/1.1 pool starvation across main and Settings windows.
   - Capped client-side concurrent conversation binds (`MAX_CONCURRENT_SESSION_BINDS=2`) with visible-surface prioritization, and moved background payload compaction and settled event folding scans onto SQLite `ReadPool` with optimistic concurrency guards to eliminate `WritePool(1)` read-scan contention.

3. **Conversation Timeline, Fork Handoff, and Workbench Polish**
   - Upgraded fork handoffs with paired source/child `ContextHandoffDivider` cards showing source model, estimated handoff tokens, and direct navigation links, alongside improved composer workspace and branch switching.
   - Refined `TurnActivity` and `TurnToolChips` live streaming tool batching, hardened floating composer inset measurements across zoomed canvas cards and late mounts, and gated automatic session review completion (`inreview` -> `done`) on foreground window visibility and focus.
   - Streamlined Bot Automations and Pulse rule proposal cards, lazy-loaded release notes inside the update badge, raised desktop/command and E2EE body limits (up to 64 MiB), mapped client image errors (`TooLarge`, `InvalidFormat`, `NotFound`) to 4xx responses, and cleaned up retired crates (`review`, `dimo-workflow-mcp`) and obsolete frontend/packaging artifacts.

### Fixes

1. **Timeline Scroll Reset Across Hidden Session Switches**
   - Fixed Chromium resetting `scrollTop` to `0` and emitting synthetic scroll events when switching back to long sessions kept mounted under `display:none`; captures a hidden-scroll snapshot on hide and synchronously restores `followTail` and scroll offsets on reveal or `0 -> >0` resize.

2. **Mirror Download HTML Error and SHA-256 Fallback**
   - Fixed MuseCode, managed toolchain (`node`/`uv`/`bun`), and Kiro installations aborting when a mirror returned an HTTP 200 HTML error page or mismatched checksum; integrity and content-type verification now run inside the per-candidate fallback loop so installs automatically fall back to upstream URLs.

3. **OpenClaw Gateway JSON5 Config Resolution and Dual-Stack Loopback Probe**
   - Fixed false-negative OpenClaw Gateway preflight checks by parsing JSON5 comments and trailing commas in `openclaw.json`, honoring `OPENCLAW_*` environment variables and `gateway.bind`/`customBindHost`, and probing `127.0.0.1` and `[::1]` concurrently with clearer local vs. remote diagnostics.

4. **Windows NSIS Fresh-Install Path Canonicalization and Stability Fixes**
   - Fixed Windows NSIS `DimoPageMainLeave` rejecting fresh install paths that do not exist on disk yet by replacing built-in `GetFullPathName` with direct Win32 `GetFullPathNameW` and `GetDriveTypeW` calls.
   - Resolved high-priority concurrency, workflow review reconciliation, Claude native driver, local file/image path resolution, and desktop file-opening regressions.
